## 🔬 Perceptron

The **Perceptron** is one of the fundamental algorithms for binary classification and provides an intuitive introduction to how artificial neurons work.

The basic computation can be represented as:

```text
z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
```

The result is then passed through an activation function to produce the prediction.

In this repository, the Perceptron is explored through practical classification experiments, including the **Iris dataset**.

---

## 🔄 Backpropagation

Backpropagation is explored to understand how neural networks learn from their errors.

The general learning process is:

```text
Input
  ↓
Forward Propagation
  ↓
Prediction
  ↓
Loss Calculation
  ↓
Backpropagation
  ↓
Gradient Calculation
  ↓
Weight Updates
  ↓
Improved Model
```

The notebooks demonstrate the transition from understanding the mathematical concept to implementing neural networks using **Keras**.
